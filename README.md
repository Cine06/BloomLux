# BloomLux

BloomLux is a static e-commerce storefront for a jewelry brand, built with HTML, CSS, and JavaScript. The site showcases rings, necklaces, bracelets, earrings, and hair pins, with product collection pages, product detail pages, shopping cart functionality, and checkout flow.

## Overview

This project is designed as a luxury boutique-style online shopping experience for jewelry products. It includes:

- Landing page with brand messaging and featured collections
- Shop listing and product detail pages
- Multiple jewelry category pages
- Shopping cart and checkout experience
- Contact and order confirmation flow
- Responsive design using Bootstrap and custom styling

## Project Structure

- `index.html` — home page
- `shop-listing.html` — shop catalog page
- `shop-detail.html` — product detail view
- `shopping-cart.html` — cart page
- `checkout.html` — checkout form
- `info-confirmation.html` — order information confirmation
- `thankyou.html` — success page
- `css/` — stylesheets
- `js/` — JavaScript files and behavior scripts
- `images/` — product and storefront imagery
- `fonts/` — custom fonts

## Features

- Elegant product presentation for luxury fashion items
- Category browsing across multiple jewelry types
- Cart count tracking using local storage
- Clean storefront layout for boutique branding
- Fully static front-end implementation

## Run Locally

Because this is a static website, you can open the project directly in a browser.

Option 1: Open `index.html` directly

Option 2: Run a local web server:

```bash
cd BloomLux
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
